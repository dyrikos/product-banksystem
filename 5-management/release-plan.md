## Стратегія випуску

1. `main` зелений у CI; наскрізні сценарії TC-30…TC-37 пройдено, протокол у [test-report](../4-quality/test-report.md).
2. `CHANGELOG.md`: перенести `[Unreleased]` у нову версію з датою; оновити `VERSION` у `CMakeLists.txt`.
3. Тег: `git tag -a v1.0.0 -m "BankSystem v1.0.0" && git push origin v1.0.0`.
4. GitHub → Releases → нова версія з тегу; нотатки з CHANGELOG; додати зібраний `bank.exe`.
