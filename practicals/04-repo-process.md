# Практична 4. Репозиторій і процес: BankSystem

**Автор:** Юра Кампов, спеціальність F2 «Інженерія програмного забезпечення» · **Дата:** 09.11.2026

## Інкремент: вузька смужка без інтерфейсу

BankSystem уже консольний: увесь шлях «номер + PIN → операція → збереження → вихід» працює в терміналі.

```bash
cmake -S . -B build && cmake --build build
printf '1\nUA1223456789\n1234\n1\n5\n' | build/bank
```

## 1. Контракт модулів

```text
money   : parse_money(текст) -> сума?            format_money(сума) -> текст
bank    : authenticate(номер, pin) -> рахунок?   deposit / withdraw(рахунок, сума) -> результат
          transfer(рахунок, номер_отримувача, сума) -> результат
          open_account(імʼя, pin) -> номер?
storage : load_accounts(місце, помилка) -> рахунки?   save_accounts(місце, рахунки) -> успіх
cli     : bank [місце сховища]                    — спільний шар запуску
```

**Перевірка за двома ознаками:**

- в операціях немає слів «файл», «SQL», «таблиця», «бібліотека» — ✅ («місце сховища», а не «файл»);
- зміна однієї вимоги зачіпає один модуль:

| Вимога змінилась | Модуль |
|---|---|
| кома замість крапки в сумі | `money` |
| PIN із 6 цифр | `bank` |
| сховище в SQLite | `storage` — так і сталося: [ADR-0004](../2-architecture/adr/0004-sqlite-storage.md) змінив лише цей модуль |
| меню українською | `cli` |

## 4. Перший коміт і конфлікт навмисно

### Історія й перший PR

Репозиторій уже має історію: у `main` — коміт v0.1.0 (оригінал) коміт v0.2.0 (модулі, тести, документи) і коміт із переходом на SQLite (ADR-0004), тег `v0.1.0`. Гілка `docs/currency-dollars` — перший pull request: валюта в документах — долари, як у програмі (зауваження ревʼю №4). Кроки публікації й саморевʼю — у [README](../README.md), розділ «Як викласти на GitHub».

```bash
git log --oneline --graph --all
```

### Конфлікт, коли автор один

Дві гілки від одного `main` змінюють **той самий рядок** у README — рядок «Стан»:

```bash
git switch -c docs/status-a
# у README: «Стан: v0.2.0 — … CI зелений на Ubuntu»
git commit -am "docs: стан — CI на Ubuntu"

git switch main
git switch -c docs/status-b
# у README той самий рядок: «Стан: v0.2.0 — … CI зелений на Windows»
git commit -am "docs: стан — CI на Windows"

git switch main && git merge docs/status-a      # без конфлікту
git merge docs/status-b                          # CONFLICT (content): Merge conflict in README.md
```

Розвʼязати: відкрити README, між `<<<<<<<` і `>>>>>>>` лишити один рядок «CI зелений на Ubuntu і Windows», прибрати маркери, `git add README.md`, `git commit`.

**Чому конфлікт у README, а не в модулях?** Модулі розділені за рішеннями: `money.cpp` і `storage.cpp` у різних задачах не перетинаються. А README — спільний для всіх задач, тож дві гілки природно правлять той самий рядок.
