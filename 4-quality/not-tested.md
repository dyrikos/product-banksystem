# Що ми свідомо не тестуємо автотестами

Покриття без цього списку виглядає повнішим, ніж є:

1. **Діалог `cli` (меню, повідомлення, неправильний пункт меню).** Автотести покривають лише логіку без консолі. Діалог перевіряється наскрізними сценаріями TC-30…TC-37 вручну; автоматизація з порівнянням виводу — у v0.3.
2. **Межу переповнення при переказі** (отримувач перевищить 999 999 999.99). Перевірка в коді є, тест — лише для поповнення (TC-39).
3. **Кирилицю в консолі Windows і дві копії програми одночасно.** Імена кирилицею в консолі Windows можуть зберегтися не в UTF-8, а дві запущені копії не зіпсують файл (SQLite блокує його), але виграє останнє збереження ([ADR-0004](../2-architecture/adr/0004-sqlite-storage.md)). Рекомендація: імена латиницею, одна копія програми.
