# ADR-0001. C++17 і CMake, консольна програма без сторонніх бібліотек

- **Статус:** прийнято, 09.11.2026. Доповнено [ADR-0004](0004-sqlite-storage.md): для сховища додано вбудовану SQLite.
- **Автор:** Юра Кампов

## Контекст

Перша версія — один файл C++ (`legacy/12main.cpp`), що збирається командою компілятора. Потрібно: тести, CI на Linux і Windows, збірка однією командою для будь-кого, хто відкрив репозиторій.

## Варіанти

| Варіант | Плюси | Мінуси | Рішення |
|---|---|---|---|
| Лишити збірку «g++ main.cpp» | нічого вчити | тести й кілька файлів збирати руками; на Windows з MSVC — інші команди | ❌ |
| CMake + GoogleTest | стандартний фреймворк тестів | залежність, яку треба завантажувати в CI й ставити локально | ❌ поки що |
| **CMake + власний мінімальний `check.h` + CTest** | одна команда збірки на будь-якій ОС; нуль залежностей | менше можливостей, ніж у GoogleTest | ✅ |
| Інша мова (Python, Java) | простіші тести | автор вивчає C++, продукт уже на C++ | ❌ |

## Рішення

C++17, CMake ≥ 3.20, CTest. Тести — `tests/check.h` (~60 рядків): `TEST`, `CHECK`, `TEST_MAIN`. На MinGW лінкуємо статично, щоб `bank.exe` запускався без DLL.

## Наслідки

- ➕ `cmake -S . -B build && cmake --build build && ctest --test-dir build` — однаково на Windows і Linux.
- ➕ CI без кроків встановлення бібліотек.
- ➖ Якщо тестів стане сотні — перейти на GoogleTest або doctest; `CHECK` тоді міняється автоматичною заміною.
