# Модулі й контракт

## Модулі

| Модуль | Файли | Відповідальність | Залежить від |
|---|---|---|---|
| `money` | `src/money.h/.cpp` | суми в копійках: розбір введеного тексту й виведення | — |
| `bank` | `src/bank.h/.cpp` | рахунки: вхід, поповнення, зняття, переказ, відкриття | `money` |
| `storage` | `src/storage.h/.cpp` | рахунки між запусками програми | `bank` (структура рахунку), SQLite 3.50.4 (`third_party/sqlite`) |
| `cli` | `src/main.cpp` | меню, діалог, повідомлення англійською | усі |

## Контракт

Описано мовою предметної області: без «файл», «таблиця», «потік».

```text
money   : parse_money(текст) -> сума?            format_money(сума) -> текст
bank    : authenticate(номер, pin) -> рахунок?   find(номер) -> рахунок?
          deposit(рахунок, сума) -> результат    withdraw(рахунок, сума) -> результат
          transfer(рахунок, номер_отримувача, сума) -> результат
          open_account(імʼя, pin) -> номер?
storage : load_accounts(місце, помилка) -> рахунки?
          save_accounts(місце, рахунки) -> успіх
результат = Ok | InvalidAmount | InsufficientFunds | SameAccount | NotFound
```

Домовленості на стиках:

- **Сума** всюди — ціле число копійок; текст «12.34» перетворює лише `money`.
- **PIN** — рядок рівно з 4 цифр; число з нього не робимо ніде.
- **`load_accounts` без рахунків** повертає порожній список, а «сховища ще немає» — `nullopt` без помилки. Це різні ситуації: перша — нормальна робота, друга — перший запуск.
- **Вказівник `Account*`** дійсний лише до наступного `open_account`: `cli` щоразу шукає рахунок за номером.

## Перевірка контракту

| Вимога змінилась | Який модуль |
|---|---|
| інший формат суми (наприклад, кома замість крапки) | `money` |
| PIN із 6 цифр | `bank` (`valid_pin`) |
| сховище в SQLite замість текстового файлу — **так і сталося** ([ADR-0004](adr/0004-sqlite-storage.md)) | лише `storage` |
| меню українською | `cli` |

Кожна зміна — в одному модулі.
